# Guía del repositorio

## Organización
- `.github/`: automatizaciones y configuración de GitHub.
- `aplicación/`: código de la aplicación.
- `componentes/`: componentes de interfaz.
- `biblioteca/`: módulos y recursos compartidos.
- `público/`: recursos públicos.
- `guiones/`: scripts auxiliares.
- `assets/`: imágenes e identidad visual del repositorio.
- `docs/`: documentación técnica.

## Criterios
1. Mantener la estructura funcional existente.
2. Documentar nuevas carpetas y módulos.
3. Evitar duplicar componentes y utilidades.
4. No guardar secretos ni credenciales en el repositorio.
5. Revisar los cambios antes de cada commit.
